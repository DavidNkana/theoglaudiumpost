# Changelog — 2026-05-25

## Changes

### Normalize Laudium product surfaces
- **What changed:** Renamed the active app folders to `frontend/` and `backend/`, and moved legacy/reference folders under `_related/`.
- **Files modified:** `AGENTS.md`, `CLAUDE.md`, `.claude/PROJECT_MAP.md`, `.gitignore`, `docs/changelog/2026-05-25.md`.
- **Why:** Chris asked for the SafAI folder to have clean product roots and for Laudium to use proper frontend/backend surfaces.
- **Docs updated:** Root agent guidance, Claude guidance, project map, and root ignore rules.
- **How to test (UI):**
  1. Start backend from `backend/` with `./mvnw spring-boot:run` or `./mvnw.cmd spring-boot:run` on Windows.
  2. Start frontend from `frontend/` with `npm run dev`.
  3. Navigate to `http://localhost:5173`.
  4. Verify the Laudium Post UI loads and API calls target `http://localhost:9011/laudium/api/v1` or the configured API base URL.
  - **Expected result:** Frontend and backend start from normalized paths.
  - **Preconditions:** Java, Maven wrapper, Node dependencies, and configured backend database/API credentials are available locally.
